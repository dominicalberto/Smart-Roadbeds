Counting vehicles with a
magnetic sensor in the road.

A simplified simulation of the vehicle detector in Knaian (2000): a baseline, a threshold with hysteresis, and a state machine. We change one parameter and compare.

· Read the thesis

The loop

Input, controller, process and output, with feedback. The published sensor only reports, so the baseline feedback is added for the simulation.

Parameters

Condition 1 uses the original threshold. Condition 2 changes only the threshold. Everything else is shared.
